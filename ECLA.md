# ECLA — Constitutional Specification (Phase 0)

ECLA is a complete learning system, not a collection of polished pages.

## Hierarchy

```
ECLA.md → Curriculum → Competencies → Language realization → Learning experiences → Scenes → Assessment → Software
```

If software disagrees with curriculum: **software is wrong**.

## Mastery ladder

```
NOT_STARTED → EXPOSED → DEVELOPING → CONTROLLED → TRANSFERRED → RETAINED
```

- **CONTROLLED** = performs with support. Unlocks progression, not demonstration.
- **TRANSFERRED** = demonstrated in a new context with real transfer evidence.
- **RETAINED** = demonstrated again after delay.

## Evidence dimensions

Comprehension, retrieval, production, interaction, transfer, retention.

No synthetic transfer scores. No `correct/total` alone as mastery.

## Product promise

> "I can actually do that in Spanish."

Everything else supports that feeling.
