# Real Learner Testing Protocol (Phase 47)

## Participants
- 3–5 learners with no prior Spanish (or documented baseline)
- No curriculum explanation before session

## Session structure (45 min)
1. Onboarding only — no coaching
2. Free navigation for 30 min
3. 15 min structured real-world probes (verbal, with facilitator)

## Observe
- Where do they hesitate?
- Where do they get bored or cheat?
- Do they use repair language spontaneously?
- Do they remember yesterday's competency?
- Can they communicate meaning without translation?

## Capture
- Screen recordings (with consent)
- Post-session questionnaire: confidence, clarity, frustration
- API logs: mastery transitions, support usage, error categories

## Success criteria
Learner can, without ECLA visible:
- Introduce themselves
- Request something politely
- Repair a misunderstanding
- Handle one unfamiliar situation

## Revision loop
Failures → curriculum fix first, UI second.
