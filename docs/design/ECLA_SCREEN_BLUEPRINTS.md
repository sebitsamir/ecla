# ECLA SCREEN BLUEPRINTS
## Core Experience Redesign

# 1. Landing

## Goal
Create immediate emotional differentiation.

## Hero
Large editorial statement:

**Learn until you can actually use it.**

Supporting line:
Ecla turns language into situations, memory, interaction, and real capability.

Primary CTA:
Start learning

Secondary:
See how Ecla works

Visual:
A cinematic language scene fragment—not a generic dashboard mockup.

---

# 2. Home

## Opening
Contextual:

“Good evening.”

Then:

**Spanish is waiting.**

Dominant next action:
Continue current scene.

Secondary:
“You can now…”

Review:
Only if something genuinely needs attention.

Never:
six metric cards.

---

# 3. Learn / Journey

Use a vertical or freeform spatial journey.

Each competency node communicates:
- objective
- state
- prerequisite
- available scene
- retained/fragile status

The map should feel like a living structure, not a game board.

---

# 4. Scene

## Stage A — Arrival
Environment and context.

## Stage B — Character
Character enters.

## Stage C — Encounter
Learner hears/sees language.

## Stage D — Response
Speak / write / choose / interact.

## Stage E — Feedback
Human-first feedback.

## Stage F — Continuation
Scene progresses naturally.

## Stage G — Reflection
Short capability statement.

---

# 5. Drill

No visual excess.

Large prompt.
Immediate answer.
Keyboard shortcuts.
Fast transition.
Subtle streak of flow inside the session, but no punitive streak system.

---

# 6. Review

Open with:

“Three things are starting to fade.”

Then immediately practice.

Avoid:
review dashboards before review itself.

---

# 7. Progress

Hero statement:

**What you can actually do**

Then:
- retained capabilities
- transfer evidence
- constellation
- recent breakthroughs
- fragile areas

XP can exist but should be tertiary.

---

# 8. Voice

Full-screen conversational interface.

Character at center/upper region.
Transcript minimal.
Speak control dominant.
Feedback conversational.

Example:

“I understood you immediately.”

Then:

“Try making _quiero_ a little softer.”

---

# 9. Missions

Opening:

MISSION

**You just arrived in Madrid.**

Objective:
Ask which platform the train to Toledo leaves from.

Constraints:
No direct translation.
Two retries.
Hints appear only if needed.

CTA:
Enter station

---

# 10. Onboarding

Minimal.

Step 1:
What language?

Step 2:
Why now?

Step 3:
How much can you already do?

Then immediately:
first micro-scene.

Avoid long preference forms.

---

# 11. Profile

Focus on identity as learner:

- current language
- capabilities
- goals
- preferences
- account

Avoid turning profile into an analytics dashboard.

---

# 12. Settings

Simple, calm, grouped.

Sections:
- Learning
- Audio & Voice
- Notifications
- Accessibility
- Privacy
- Account

---

# 13. Empty States

Course:
“Your next path appears after you finish this scene.”

Review:
“Nothing needs review yet.”

Voice:
“Your microphone is ready when you are.”

---

# 14. Loading States

Home:
“Finding the right next step…”

Scene:
“Preparing the café…”

Voice:
“Listening…”

Progress:
“Updating what Ecla knows you can do…”

---

# 15. Error States

Scene:
“We couldn't load this scene.
Your progress is safe.”

Voice:
“We couldn't hear that clearly.
Nothing was submitted.”

Auth:
“Your session expired.
Sign in again to continue.”

---

# 16. Mobile Blueprint

Home:
- contextual title
- full-width Continue Journey
- single capability card
- bottom nav

Scene:
- full-screen environment
- compact dialogue
- bottom action zone
- voice control thumb reachable

Progress:
- horizontal capability sections
- simplified constellation
- tap node for detail

---

# 17. Premium Interaction Details

- hover reveals context, never unnecessary decoration
- primary buttons use light and tonal contrast, not giant gradients
- selected nav has quiet motion continuity
- scene surfaces respond subtly to voice and progress
- long pages use section rhythm, not endless cards
- all transitions maintain spatial relationship where possible

---

# 18. First Screens to Rebuild

Priority order:

1. Home
2. Scene Player
3. Learn / Journey
4. Review
5. Voice
6. Progress
7. Onboarding
8. Missions
9. Profile / Settings
10. Admin

The first three define the visual benchmark for everything else.
